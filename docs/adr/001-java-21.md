# ADR 001: Java 21 as Primary Language

## Status
Accepted

## Context
We need a robust, typed language for the backend API and data processing microservices that can integrate easily with large enterprise ecosystems.

## Decision
We will use Java 21 LTS.

## Consequences
- Access to virtual threads (Project Loom) for high-concurrency data serving without thread-pool exhaustion.
- Pattern matching and records reduce boilerplate code for data transfer objects (DTOs).
- Requires team members to stay updated on modern Java features, deviating from legacy Java 8/11 paradigms.
